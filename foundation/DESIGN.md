# CET-4 词缀翻卡记忆站 — 设计文档

> 版本：v1.0（MVP）
> 技术栈：原生 HTML / CSS / JavaScript，零依赖，零构建
> 数据源：手工整理的词缀分组数据（`data/words.js`）

---

## 1. 产品定位与核心玩法

以**词缀（前缀 / 后缀 / 词根）**为组织单位,把四级单词按"同族"成组呈现。用户先看词缀的含义,再用 5 个左右的同族单词做**翻卡自测**,通过"先回忆、再核对"的方式完成记忆。

一句话玩法：**看词缀 → 猜词意 → 翻卡核对 → 下一组。**

与普通单词表的关键差异在于 `breakdown` 字段——用户看到的不只是 `review = 复习`,而是 `re-(再) + view(看) → 再看一遍 → 复习`。这是本产品的核心价值,不是可选装饰。

## 2. MVP 范围

### 2.1 做

- 单词数量选择（任意数量,末组不满）
- 按词缀分页的学习界面
- 词缀介绍面板
- 单词卡 / 释义卡双面翻转
- 今日进度记录与刷新恢复（localStorage）
- 完成页 + 「回到主界面」「添加单词」
- 键盘快捷键
- 响应式布局（桌面横排 / 窄屏竖排）

### 2.2 不做（留给后续版本）

| 项目 | 说明 |
|---|---|
| 登录、后端、数据库、云同步 | MVP 纯前端,数据存本地 |
| 间隔重复算法（SRS） | 需要复习队列与遗忘曲线,后置 |
| 发音 TTS、拼写测验、选择题 | 属于独立模块 |
| 学习统计图表、成就系统 | 依赖历史数据积累 |
| 主题换肤、动画精修 | 一个 CSS 3D 翻面过渡即够 |

## 3. 信息架构与状态机

```
home（主界面）
  │
  ├─ 无今日记录      → 按钮「开始今日学习」 ┐
  ├─ 有未完成场次    → 按钮「继续今日学习 (3/7)」→ 直接恢复 learning
  └─ 今日已完成      → 按钮「再学一组」     ┘
                                            ↓
                              countSelect（选择数量）
                                            ↓
                              learning（第 i 页 / 共 M 页）
                                            ↓
                              complete（今日单词学完了）
                                    ├─ 回到主界面 → home
                                    └─ 添加单词   → countSelect（续接,不重复）
```

**关键约束**：「添加单词」不是重新开始,而是**在今日场次后追加新的页**,且必须跳过今日已学的单词。这由第 6 章的取词游标天然保证。

## 4. 界面设计

### 4.1 布局（桌面 ≥ 1024px）

```
┌──────────────────────────────────────────────────────────────┐
│  第 1/2 页 · 已学 5 个单词 · 用时 03:12          [上一组]     │  ← 顶部栏
├──────────────────────────────────────────────────────────────┤
│              │                                               │
│   ┌───────┐  │  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │
│   │  re-  │  │  │review│ │return│ │recall│ │repair│ │remind│ │  ← 单词卡 ×5
│   │       │  │  │/rɪˈ..│ │/rɪˈ..│ │/rɪˈ..│ │/rɪˈ..│ │/rɪˈ..│ │
│   │ 前缀  │  │  └──────┘ └──────┘ └──────┘ └──────┘ └──────┘ │
│   │ 再、重新│ │                                               │
│   │       │  │  ┌──────────────────────────────────────────┐ │
│   │ 常表示重复│ │  │ v. 复习；回顾                             │ │  ← 释义卡（滑出）
│   │ 或返回…│  │  └──────────────────────────────────────────┘ │
│   └───────┘  │                                               │
│   词缀面板    │                    〔下一组 →〕                │  ← 右下角
└──────────────────────────────────────────────────────────────┘
```

- **词缀面板（最左,固定宽 ~280px）**：词缀本体 + 类型徽标（前缀/后缀/词根）+ 中文含义 + 一句话说明。整页不变,切页时更新。点击可展开更多说明（可选）。
- **单词卡区（右侧,横排 5 张）**：每张约 200px 宽,超出后自动换行或横向滚动。
- **释义卡（下方,宽度与单词卡区对齐）**：初始隐藏,点击单词卡后从下方滑出。
- **「下一组」按钮（右下角）**：始终可点,不阻塞。

### 4.2 布局（窄屏 < 768px）

词缀面板移到顶部折叠,单词卡改为**竖排列表**（每行一张,占满宽度）。释义卡紧跟在被点击的单词卡下方,而非统一在底部——竖排时"底部弹出"会导致用户看不到卡片与释义的对应关系。

### 4.3 主界面

居中：产品名 + 一句说明 + 主按钮（文案随今日状态变化,见第 3 章）+ 今日状态行（`今日已学 7 个单词 · 2 个词缀`）。

### 4.4 数量选择页

- 预设按钮：`5` `10` `15` `20`
- 自定义：`− / +` 步进（步长 1,范围 1~50）
- **实时预览文案**（重要）：
  - `共 7 个单词,分 2 组（第 2 组 2 个）`
  - 剩余新词不足时：`剩余新词仅 4 个,本次将学完`
- 「开始学习」按钮

### 4.5 完成页

- 居中大字：**今日单词学完了**
- 统计行：`今天学了 7 个单词、2 个词缀,用时 06:41`
- 两个按钮：`回到主界面`（次要样式） / `添加单词`（主要样式）

## 5. 卡片翻面交互规范

卡片有三种状态：`hidden`（释义卡未出现）/ `front`（正面）/ `back`（背面）。

### 5.1 状态表

| 卡片 | 正面内容 | 背面内容 |
|---|---|---|
| 单词卡 | 单词 + 音标 | 词根拆分 + 助记（`breakdown`） |
| 释义卡 | 词性 + 中文释义 | 例句 + 例句翻译 |

### 5.2 点击行为

| 触发 | 结果 |
|---|---|
| 点击单词卡（释义卡为 `hidden`） | 释义卡从下方滑出,显示正面。**单词卡不翻面** |
| 点击单词卡（释义卡已显示） | 单词卡翻面（`front` ⇄ `back`）,可反复翻回 |
| 点击释义卡 | 释义卡翻面（`front` ⇄ `back`）,可反复翻回 |
| 点击另一张单词卡 | 释义卡切换到该词的内容,回到 `front`；前一张单词卡的翻面状态保留 |

### 5.3 状态标记

- 单词卡一旦被点击过,右上角出现一个小圆点,表示"这词我看过了"。
- 翻面为**可逆**操作,但 `flipped` 布尔值一经置 `true` 即永久保留（用于进度统计与页内提示）。
- 翻面为**本页内状态**,切到下一页时重置为 `hidden`；通过「上一组」返回时恢复。

### 5.4 进度提示

右下角「下一组」按钮旁边显示 `还有 2 个单词没看`；全部看过则显示 `本组已看完整 ✓`。按钮本身在任何情况下都可点击。

### 5.5 键盘快捷键

| 按键 | 行为 |
|---|---|
| `1`~`5` | 等价于点击第 n 张单词卡 |
| `空格` | 翻面当前聚焦的卡（无聚焦则作用于第 1 张单词卡） |
| `→` / `Enter` | 下一组 |
| `←` | 上一组 |

## 6. 取词与分组算法（核心）

因为允许任意数量,必须解决"末组不满 5 个词"以及"下次从哪继续"的问题。方案是**全局取词游标**。

### 6.1 数据流

把词缀数据展平成一个线性流（词缀连续排列）：

```
[re-: review, return, recall, repair, remind] [pre-: preview, predict, ...] [port: ...] ...
```

### 6.2 取词

```js
function takeWords(count) {
  const stream = AFFIXES.flatMap(a =>
    a.words.map(w => ({ affixId: a.id, wordId: w.id }))
  );
  const start = loadCursor();                       // 全局游标
  const slice = stream.slice(start, start + count); // 可能短于 count
  saveCursor(start + slice.length);                 // 游标前移
  return groupByAffix(slice);                       // 按词缀切页
}
```

- `groupByAffix` 只做**相邻同词缀**合并,因此结果必然保持顺序。
- 游标永远不会回退,所以**同一批单词不会被重复发放**,「添加单词」天然续接、不重不漏。
- 若某一页正好是某词缀的后半段（例如 `pre-` 的第 3~5 个词）,词缀面板照常显示该词缀介绍——这不影响教学完整性。

### 6.3 示例

假设 `pre-` 有 5 个词,用户第一次选 7：

| 页 | 词缀 | 单词数 |
|---|---|---|
| 1 | `re-` | 5 |
| 2 | `pre-` | 2 |

用户点「添加单词」再选 6：

| 页 | 词缀 | 单词数 |
|---|---|---|
| 3 | `pre-` | 3（即 `pre-` 的第 3~5 个词） |
| 4 | `port` | 3（即 `port` 的第 1~3 个词） |

### 6.4 剩余不足

剩余新词少于所请求数量时：取走全部剩余词,并在进入学习页前提示 `今日新词已学完,本次共 4 个`。若剩余为 0,数量选择页整体置灰并显示 `所有单词都学完啦,后续版本将提供复习模式`。

## 7. 数据结构

### 7.1 词缀数据（`data/words.js`）

```js
window.CET4_AFFIXES = [
  {
    id: "re",                        // 唯一标识,用于取词与分组
    affix: "re-",
    type: "前缀",                     // 前缀 | 后缀 | 词根
    meaning: "再、重新；向后",
    note: "常表示重复或返回,置于动词、名词前。",
    words: [
      {
        id: "review",
        word: "review",
        phonetic: "/rɪˈvjuː/",
        pos: "v.",
        meaning: "复习；回顾",
        breakdown: "re-(再) + view(看) → 再看一遍 → 复习",
        example: "I review the new words every evening.",
        exampleZh: "我每天晚上复习新单词。"
      }
      // ... 本词缀共 5 个词
    ]
  }
  // ...
];
```

**约定**：
- `words` 数组建议 5 个,允许 3~6 个,但**同一词缀的词必须连续存放在一起**（取词算法依赖这一点）。
- `words[].id` 在同一词缀内唯一即可；卡片标识统一用 `${affixId}:${wordId}`,避免跨词缀同词冲突。
- MVP 数据目标：**20 个词缀 × 5 词 = 100 词**，先跑通交互再扩量。

### 7.2 今日场次（localStorage `cet4.session.v1`）

```js
{
  date: "2026-02-14",
  startedAt: 1739520000000,
  pages: [
    { affixId: "re",  wordIds: ["review","return","recall","repair","remind"] },
    { affixId: "pre", wordIds: ["preview","predict"] }
  ],
  currentPage: 0,
  cardState: {                                  // key = `${affixId}:${wordId}`
    "re:review": { revealed: true, flipped: true }
  },
  completed: false
}
```

场次自包含全部页与卡片状态,**刷新后可直接恢复,无需重新取词**（游标已前移,重新取词会漏词）。

### 7.3 其他存储键

| 键 | 内容 |
|---|---|
| `cet4.cursor.v1` | 全局取词游标（number） |
| `cet4.session.v1` | 今日场次对象 |
| `cet4.history.v1` | `[{ date, words, affixes, minutes, completed }]`,仅供主界面展示连续天数（可选） |

### 7.4 跨天处理

进入 `home` 时检查 `session.date`：
- 等于今天 → 按第 3 章三态判断。
- 不等于今天 → 把旧场次归档进 `history`（若 `completed` 为 false 也照常归档,不惩罚用户）,重置今日场次。**游标不清空**,保证取词连续性。

## 8. 应用状态与渲染

单一状态对象 + 单一 `render()` 函数,不做组件拆分。

```js
const state = {
  view: "home",           // home | countSelect | learning | complete
  session: null,          // 见 7.2
  draft: { count: 5 },    // 数量选择页的临时值
  focus: null,            // 当前聚焦的卡片 key
  tick: 0                 // 计时器刷新用
};

function render() { /* 按 state.view 分支,整体重建 DOM */ }
```

- 事件用**委托**：在容器上监听一次 `click`,通过 `data-action` / `data-card` 属性分发。
- 每次状态变更后立即 `render()` + `saveSession()`。MVP 数据量极小,整体重建无性能问题。

```

├─ app.js          状态机 + 渲染 + 持久化

├─ README.md       如何运行
```

**注意**：数据必须用 `.js` 全局变量而非 `fetch('words.json')`——直接双击 `index.html` 时 `file://` 协议下 `fetch` 会被 CORS 拦截。这决定了零依赖方案能否真正"双击即用"。

## 10. 样式要点

- **翻面动画**：外层 `perspective: 1000px`,内层 `transform-style: preserve-3d` + `transition: transform .45s`,正反面用 `backface-visibility: hidden`（并补 `-webkit-` 前缀,兼容 Safari）,背面初始 `rotateY(180deg)`。
- **长单词自适应**：按字符长度分档降字号（如 >10 字符降至 0.8 倍）,或 `clamp()` 配合 `word-break: break-word`。
- **释义卡滑出**：`max-height` + `transform: translateY()` 过渡,避免撑动整页布局。
- **配色**：单一强调色 + 中性灰阶。正面/背面用底色区分（正面浅、背面浅暖色）,使用户一眼看出是否已翻面。
- **可访问性**：卡片用 `<button>` 而非 `<div>`,保留焦点环,`aria-pressed` 标记翻面状态。

## 11. 边界情况清单

| # | 情况 | 处理 |
|---|---|---|
| 1 | 数量不是 5 的倍数 | 末页不满,靠取词游标保证续接（第 6 章） |
| 2 | 「添加单词」重复发词 | 游标只前进不回退,天然不重复 |
| 3 | 剩余新词不足所请求数量 | 取走全部剩余并提示 |
| 4 | 剩余新词为 0 | 数量选择页置灰,提示等待复习模式 |
| 5 | 刷新 / 关闭页面 | 从 `session` 恢复当前页与卡片状态 |
| 6 | 跨天打开 | 旧场次归档,游标保留 |
| 7 | 误触「下一组」 | 提供「上一组」按钮（idea.txt 未提及,建议加入,理由:低成本容错） |
| 8 | 窄屏 5 卡横排挤压 | 断点 < 768px 切竖排列表 |
| 9 | 单词缺失 `breakdown` | 背面降级显示 `该词暂无助记`,不报错 |
| 10 | 词缀不足 5 个词 | 允许 3~6 个,不补占位卡 |
| 11 | 快速连点「下一组」 | 末页时按钮置灰或直接进入完成页,防止跳过 |

## 12. 验收标准（Definition of Done）

- [ ] 主界面三种状态文案正确切换
- [ ] 选 7 个单词 → 得到 2 页（5 + 2）,词缀面板分别正确
- [ ] 点「添加单词」再选 6 → 得到 `pre-` 剩余 3 词 + `port` 3 词,**无重复词**

- [ ] 走完所有页 → 出现「今日单词学完了」+ 两按钮,`添加单词` 可继续
- [ ] 键盘 `1~5` / `空格` / `→` 生效
- [ ] 375px 宽度下可正常使用（竖排,释义卡跟随单词卡）
- [ ] 双击 `index.html`（`file://`）可直接运行,无需服务器

## 13. 后续路线图
